## Overview

This course provides a step-by-step guide to building an MVC web application using the **Symfony 8.1** framework and the **PHP 8.4** language. HTML pages are generated by the server using **Twig** views, without a client-side JavaScript framework. Data access is handled via the **Doctrine** ORM.

It adapts the course [Step-by-Step Introduction to the [Laravel](https://stahe.github.io/en-laravel-sept-2026/) Web Framework]—which itself is based on the [Flask](https://stahe.github.io/flask-sept-2026/) courses— [Spring MVC](https://stahe.github.io/springmvc-sept-2026/), [ASP.NET Core MVC](https://stahe.github.io/aspnetcoremvc-sept-2026/), and [NestJS](https://stahe.github.io/nestjs-html-sept-2026/). The examples have the same numbers and cover the same topics: you can compare the frameworks example by example.

## Contents

| Chapter | Topics | Examples |
|---|---|---|
| Actions, Routing, Responses | routes (`#[Route]`), controllers, responses, redirects, service container | 01 to 06 |
| The Action Model | request parameters, argument resolvers, validation constraints, POST requests | 07–12 |
| The View and Its Model | Twig, templates, macros, extensions, Form component, validation, Post/Redirect/Get, CSRF protection | 13–21 |
| Internationalization | an application in French and English (YAML dictionaries, ICU messages) | 22 |
| Data scopes | request, session, cache, cookies | 23 |
| The request lifecycle | core events, listeners, argument resolvers, error pages | 24 |
| Authentication and Authorization | firewall, JWT authenticator in a cookie, roles, CAPTCHA, rate limiting | 25–27 |
| Layered Architecture | web / business logic / DAO with Doctrine and MySQL | 28 |
| Case Study | **RdvMedecins**, a medical appointment scheduling application, explained file by file | - |

The `rdvmedecins2-symfony` case study manages three roles (administrator, doctors, patients): calendars, bookings, doctor and client management, CAPTCHA-protected account creation, and a French/English interface. It uses the same `dbrdvmedecins2` database as the other versions of the application.

## Prerequisites

- PHP 8.4 or newer (extensions `intl`, `mbstring`, `openssl`, `pdo_mysql`);
- Composer 2;
- MySQL 8 or MariaDB (Laragon on Windows);
- Visual Studio Code with the PHP Intelephense, Twig Language 2, and YAML extensions;
- curl.

The source code can be downloaded from the course website. The `vendor` folders are not included there: `composer install` creates them—one in the `exemples` folder and one in the `rdvmedecins2-symfony` folder.
